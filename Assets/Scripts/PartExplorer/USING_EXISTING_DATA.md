## Quick Setup (15 Minutes)

### 1. Create PartExplorerData
```
Right-click → Create → Engine VR → Part Explorer → Part Explorer Data
Name: "V8HotRodExplorer"
```

### 2. Auto-Populate
```
Create GameObject "PopulatorHelper"
Add PartExplorerAutoPopulator component
Assign:
  - Engine Part Manifest: V8HotRedManifest
  - Explorer Data: V8HotRodExplorer
  - Engine Root: Your V8 engine
Click "Populate Explorer Data"
Delete PopulatorHelper
```

### 3. Add Components
```
Create "PartExplorerSystem"
Add PartExplorerController
Assign V8HotRodExplorer
```

### 4. Create UI
```
Add 5 UI elements to tablet:
- Part Name Text
- Part Description Text
- Part Counter Text
- Previous Button
- Next Button
```

### 5. Wire UI Panel
```
Create "PartExplorerUIManager"
Add PartExplorerUIPanel
Assign all UI elements
```

### 6. Wire Button
```
Select "Show Working" button
Add PartExplorerLauncher
Wire OnClick → LaunchExplorer()
```

### 7. Test!
```
Play scene
Click "Show Working"
See parts with your existing data!
```

## The Auto-Populator Does This

```csharp
// 1. Read V8HotRedManifest
foreach (var entry in manifest.parts)
{
    // 2. Get part name and description
    string name = entry.partData.partName;
    string description = entry.partData.description;
    
    // 3. Find EnginePart in scene
    EnginePart part = FindPartInScene(entry.gameObjectName);
    
    // 4. Add to PartExplorerData
    explorerData.AddPart(name, description, part);
}
```
